SensSquare Beta — Architecture Breakdown

SensSquare Beta is a desktop automation and testing application built in Python using the tkinter GUI framework. Designed specifically for railway signaling software testing, it integrates automated macro execution (via external macro tools like Mini Mouse Macro), real-time screen/pixel region monitoring, automated Excel report generation, and Telegram bot remote control and alert systems.

🏗️ Core Architecture & Component Breakdown
1. Global Configuration & Utilities
  • COLORS & AppConfig: Defines a unified color scheme (Red/Blue theme) and central configuration constants such as timeout intervals, file paths, macro execution parameters, and Telegram message templates.
  • DataLogger: Thread-safe event logging utility that captures system activities, user actions, warnings, and errors with high-precision timestamps. Limits maximum log entries to prevent memory bloat.
2. User Authentication & Logging
  • LoginApp: Provides a secure login dialog before loading the main interface. Captures railway-specific operational metadata including Username & Password, Station Name & Code, Railway Zone & Division (with dynamic filtering), and Project Code.
  • DataLoggerApp: A dedicated GUI window (SUAL) that displays color-coded system logs in real time, allowing users to review, refresh, or clear logs.
3. Remote Management & Telegram Integration
  • TelegramBot: Runs a background long-polling thread to connect with the Telegram Bot API.
  • Alert Notifications: Sends real-time updates for macro execution start/completion, aborts, signal failures, and monitor timeouts.
  • Remote Control Commands: Allows users to issue commands via Telegram chat (e.g., /status, /pause, /resume, /stop, /routes, /progress, /enable_alerts, /disable_alerts).
  • Reliability Features: Includes rate-limiting, thread-safe message queues, and automatic connection recovery.
  • TelegramSettingsApp: A configuration dialog to set up bot tokens, chat IDs, toggle alerts/remote controls, and test API connections.
4. Hardware Interaction & Hotkey Management
  • MacroKeyListener: Utilizes pynput to listen globally for system hotkeys.
  • Allows users to dynamically trigger Emergency Stop or Pause/Resume actions during macro execution from anywhere in the system.
  • Includes key debouncing and thread safety to avoid duplicate triggers.
5. Main UI Application Framework
  • TabbedApplication: The core controller managing the application UI layout.
  • Header Banner: Displays user greeting, station/project details, and a dynamic multi-state status indicator ("bubbles") showing system readiness.
  • Notebook Tabs: Houses two primary modules:
    • Macro Runner Tab: Coordinates batch execution of mouse macros based on loaded Excel sheets.
    • Signal Monitor Tab: Handles live image-processing and region monitoring for visual/pixel changes.
  • Help & About Windows: Includes an animated help documentation viewer and slogan marquee.
